# Galleria Fotografica - Vue3

Galleria fotografica realizzata con Vue3 e Composition API.

## Caratteristiche

- Dropdown per selezionare album fotografici
- Griglia di foto responsive
- Visualizzazione foto a dimensioni originali con navigazione
- Interfaccia moderna e intuitiva

## Installazione

```bash
npm install
```

## Sviluppo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Struttura Album

Gli album sono organizzati nella cartella `public/images/` con sottocartelle per ogni destinazione.
